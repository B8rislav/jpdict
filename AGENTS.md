## Overview

Next.js 15 (App Router) frontend in React 19 for studying Japanese and Chinese —
morphological analysis, dictionary lookup, and AI grammar explanations.
State is [Effector](https://effector.dev); components are documented in Storybook and
tested with Vitest. UI components are **migrating from [Gravity UI](https://gravity-ui.com)
(`@gravity-ui/uikit`) to [Designoslav](https://github.com/B8rislav/designoslav)** — the
in-house design system (`designoslav` package, local checkout at
`~/Documents/designoslav`). New/changed UI should use Designoslav where it has the
component; don't add new Gravity usage. See [docs/STYLING.md](docs/STYLING.md).
It talks to a **separate FastAPI backend** (default `http://localhost:8000`); the Next.js
side also runs a thin BFF layer under `src/app/api` (see [docs/BFF.md](docs/BFF.md)).

## Commands

| Command | What it does |
|---------|--------------|
| `npm run dev` | Dev server with hot reload — http://localhost:3000 |
| `npm run build` | Production build to `.next/` |
| `npm test` | Vitest unit tests (`--project unit`) |
| `npm run test:storybook` | Storybook component tests, headless (`--project storybook`) |
| `npm run lint` | ESLint via `next lint` |
| `npm run check:stories` | Fails if a `ui/` component has no sibling `*.stories.tsx` |
| `npm run verify` | lint + check:stories + `tsc --noEmit` + unit tests |
| `npm run format` | Prettier write over `src/**` |
| `npm run storybook` | Storybook dev server — http://localhost:6006 |
| `npm run generate-types` | Regenerate `src/shared/api/generatedTypes.d.ts` from the backend's live OpenAPI at `:8000/docs` (**backend must be running**) |

Node version is pinned in `.nvmrc` — run `nvm use` first.

## Architecture map

FSD-ish layout under `src/` (full walkthrough: [docs/STRUCTURE.md](docs/STRUCTURE.md)):

- `src/app` — App Router routes + the BFF route handlers in `src/app/api`
- `src/features/*` — one folder per feature (`Search`, `WordCard`, `Dictionary`, `Auth`, …).
  Each owns a `ui/` (view), a `model/` (Effector logic), an `api/` when it calls the
  backend, plus a container component that wires model → view.
- `src/shared` — `ui/` (primitives), `api/` (`types.ts`, generated types, fetch helpers),
  `i18n/`, `utils/`
- `src/stores` — top-level Effector stores (`auth`, `userProfile`)

**view = dumb / model = logic.** Enforced three ways, because no single rule suffices:

1. `effector`, `effector-react`, and `@/stores/*` are banned in every `.tsx` under
   `src/features` / `src/shared` **except** a whitelist of container files
   (`STATEFUL_FILES` in `eslint.config.mjs`). It's a whitelist deliberately — the old rule
   denied those imports inside `**/ui/**`, which any component could escape by not living
   in a `ui/` folder, and five did.
2. `max-lines: 100` on containers, pages, and layouts.
3. `npm run check:stories` — every `ui/` component needs a story.

See [docs/STATE.md](docs/STATE.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Conventions

- **No hardcoded UI strings.** Use `t('category', 'key')` from `@/shared/i18n`
  (locales: `ru` default, `en`). An ESLint rule blocks Cyrillic string literals in
  `.tsx` files — that error means "move it into `ru.json`/`en.json`". See [docs/I18N.md](docs/I18N.md).
- **Storybook story per view component** — every `ui/*View.tsx` gets a `*.stories.tsx`.
  See [docs/COMPONENTS.md](docs/COMPONENTS.md) and [docs/TESTING.md](docs/TESTING.md).
- **CSS Modules** + CSS custom properties for styling. See [docs/STYLING.md](docs/STYLING.md).
- In docs, reference code locations as `path:line` plain text (links rot); elsewhere
  markdown links are fine.
- Everytime after writing something search for common abstractions in other components or functions to shorten code

## Gotchas

- `uiLocale` (interface language, ru/en) ≠ `selectedLanguage` (study language, jp/cn) —
  they are independent.
- **Don't hand-edit `src/shared/api/generatedTypes.d.ts`** — it's generated by
  `npm run generate-types`.
- The window is the only scroll surface (no nested scroll containers). See [docs/UX.md](docs/UX.md).
- `designoslav` is installed from its GitHub repo, not the local checkout — after
  changing the design system, push it and run `npm update designoslav` here to pick
  up the change.
