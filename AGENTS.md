## Overview

Next.js 15 (App Router) frontend in React 19 for studying Japanese and Chinese —
morphological analysis, dictionary lookup, and AI grammar explanations.
State is [Effector](https://effector.dev), UI is [Gravity UI](https://gravity-ui.com)
(`@gravity-ui/uikit`), components are documented in Storybook and tested with Vitest.
It talks to a **separate FastAPI backend** (default `http://localhost:8000`); the Next.js
side also runs a thin BFF layer under `src/app/api` (see [docs/BFF.md](docs/BFF.md)).

## Architecture map

FSD-ish layout under `src/` (full walkthrough: [docs/STRUCTURE.md](docs/STRUCTURE.md)):

- `src/app` — App Router routes + the BFF route handlers in `src/app/api`
- `src/features/*` — one folder per feature (`Search`, `WordCard`, `Dictionary`, `Auth`, …).
  Each owns a `ui/` (view), a `model/` (Effector logic), an `api/` when it calls the
  backend, plus a container component that wires model → view.
- `src/shared` — `ui/` (primitives), `api/` (`types.ts`, generated types, fetch helpers),
  `i18n/`, `utils/`
- `src/stores` — top-level Effector stores (`auth`, `userProfile`)

**view = dumb / model = logic.** This is ESLint-enforced: files under any `ui/` folder
may not import `effector-react` or `@/stores/*` — pass data in via props. See
[docs/STATE.md](docs/STATE.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Conventions

- **No hardcoded UI strings.** Use `t('category', 'key')` from `@/shared/i18n`
  (locales: `ru` default, `en`). An ESLint rule blocks Cyrillic string literals in
  `.tsx` files — that error means "move it into `ru.json`/`en.json`". See [docs/I18N.md](docs/I18N.md).
- **Storybook story per view component** — every `ui/*View.tsx` gets a `*.stories.tsx`.
  See [docs/COMPONENTS.md](docs/COMPONENTS.md) and [docs/TESTING.md](docs/TESTING.md).
- **CSS Modules** + CSS custom properties for styling. See [docs/STYLING.md](docs/STYLING.md).
- In docs, reference code locations as `path:line` plain text (links rot); elsewhere
  markdown links are fine.

## Gotchas

- `uiLocale` (interface language, ru/en) ≠ `selectedLanguage` (study language, jp/cn) —
  they are independent.
- **Don't hand-edit `src/shared/api/generatedTypes.d.ts`** — it's generated by
  `npm run generate-types`.
- The window is the only scroll surface (no nested scroll containers). See [docs/UX.md](docs/UX.md).
